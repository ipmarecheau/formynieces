# SmoothSeas Mobile App Interactive Prototype

Open `index.html` in a browser to click through the proposed Flutter mobile app experience.

The mockup contains two role-based experiences:

- **Child app:** Today, Voyage, Practice, Re-teach feedback, Result/reward moment.
- **Parent app:** Overview, Children, Weak topics, Readiness, Writing.

The design keeps SmoothSeas' current brand direction: warm paper background, teal/amber palette, Smooth the turtle, voyage language, and SEA-specific messaging. The UX direction is intentionally closer to Duolingo: one daily action, visible streak/progress, short practice, and a reward moment.

This is a prototype artifact, not production app code. It should guide the Flutter build and help decide what to keep, simplify, or cut before implementation.
